🪔 Diwali Animation Project

A festive web project built to celebrate the beautiful festival of lights — *Diwali*!  
This project includes colorful *animations, **wishes*, and an engaging design to spread joy and positivity.

- 🎆 Animated Diwali lights and effects
- 💬 Warm greeting messages

- ✅ CSS

1. *Download* or *clone* this repository.

## 🪔 About Diwali

> *Diwali, also known as Deepavali, is one of India's biggest festivals, symbolizing the triumph of **light over darkness* and *good over evil*. Homes are decorated with diyas (lamps), rangoli, and fireworks, creating a magical atmosphere.
